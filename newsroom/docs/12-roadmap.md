## Phase 4：增长与商业化

| 项 | 内容 |
|---|---|
| 账号分析 | 每个账号独立基线（相对自身中位数），不跨账号比较绝对曝光 |
| 内容实验 | 角度 / 标题 / 图卡 A/B，按时间窗口和主题对照；样本不足不下结论 |
| 读者洞察 | 合法授权的数据：真实讨论、术语困惑、纠错评论 → 待研究问题与下周选题；禁止自动回复和诱导互动 |
| 创新实验室 | 创新 Agent 只提交提案（机会、价值、可行性、复杂度、风险、MVP、优先级），不能改生产系统或开新账号 |
| 转化追踪 | UTM 链接到 AlphaScope 公开页 → 注册 / 订阅；不做欺骗性营销 |

## 商业化路径

```
X 报道（免费、可核验） → 公开故事页（完整时间线、纠错记录）
  → 交易员历史研究（AlphaScope 档案） → 高级会员 / 付费追踪 / 研究订阅
```

| 收入 | 前提 |
|---|---|
| X 原创内容奖励 | 人工原创与发布，遵守平台规则；不作为唯一来源，也不承诺 |
| AlphaScope 高级会员 | 公开页到会员页的转化路径 |
| 付费巨鲸追踪 / 专题情报 | 故事引擎 + 实时提醒（AlphaScope 已有告警基础设施） |
| 研究报告 / Newsletter | 周报、月度预测账本、真实性调查 |
| 数据 API / 机构情报 | Feed 契约的对外版本（需要独立鉴权、限流和合规审查） |
| 合规品牌合作 | 明确标注赞助，不影响选题与事实 |

## 上线顺序建议

1. 服务器安装 Newsroom，做 09 §7 四个演练。
2. 配置一个真实模型，影子运行一周：AI 照常评估和起草，不发布，人工检查守卫拦截原因与选题质量，调整阈值和提示词版本。
3. 先启用一个账号（中文或英文），每日上限 3 条，跑两周再加第二个账号。
