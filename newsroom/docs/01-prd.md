# 01 产品需求（PRD）

## 1. 一句话

把 AlphaScope 可核验的真实交易数据，变成多个有差异化价值的专业媒体内容：程序发现新闻、事实包锁定数字、AI 起草不同角度、人审核并人工发布，全程可追溯。

成功标准不是生成多少篇稿，而是：**每条发布内容都能追溯到证据，不同账号之间没有换词式重复，读者因为独家数据而关注。**

## 1.1 数据源定位（2026-11-23 确定）

- **Hyperliquid 是主数据源**：链上完全公开，任何人都能复核，是品牌和 X 账号的核心。
- **OKX、币安的数据随时可能被平台隐藏**：只作为补充，不能成为任何核心栏目的唯一依据。
- **OKX 内容单独发布到 OKX 广场**：OKX 事件和依赖 OKX 数据的栏目（N1、N2）只分配给 OKX 广场账号，不进 X 账号。
- 任何非 Hyperliquid 数据源中断，只会阻断依赖它的内容，Hyperliquid 这条线不受影响。

## 2. 产品结构

一个事实中心 + 一个中央编辑部 + 多个 AI 角色 + 多个独立账号 + 一个分析中心。

```
AlphaScope（只读 Feed）
  → 同步与标准化（source_event / position_episode）
  → 程序化检测（规则 d1）→ 新闻事件（唯一、幂等）
  → 事实包（fp.v1，版本化）+ 可信度门（硬条件）+ 可解释评分（s1）
  → 故事关联（交易员连续剧）
  → AI 总编辑：报不报、为什么、哪些账号、什么角度、哪些账号保持沉默
  → 分派（人接受 / 拒绝）→ AI 记者起草 / 人工撰写（不可变版本）
  → 事实守卫（g1，硬门）→ 审核 → 图卡
  → 人工在 X 发布 → 记录帖子 → 表现录入
  → 事实变化 → 自动找出受影响稿件与已发内容（更正记录）
```

## 3. 角色

| 角色 | 能做什么 |
|---|---|
| 管理员 | 用户、模型、提示词、规则、预算；所有编辑操作 |
| 总编辑 | 所有账号的编辑操作；事件立项与拒绝；紧急停止 |
| 编辑 | 被授权账号的撰稿与审核；事件立项 |
| 记者 | 被授权账号的撰稿 |
| 审核员 | 被授权账号的审核 |
| 账号运营 | 被授权账号的发布记录、撤稿、表现录入 |
| 分析员 | 只读 |

AI 角色（内部编辑角色，不对外冒充任何真人）：Phase 1 有 AI 总编辑、AI 记者；Phase 2 扩展突发、巨鲸调查、数据研究、衍生品风险、历史故事记者，以及中英文编辑、事实核查员、增长研究员。

## 4. Phase 1 功能（本次交付）

| 模块 | 功能 |
|---|---|
| 数据同步 | 增量游标、滞后截断、幂等、回放兜底、积压检测、熔断与失败记录 |
| 检测 | 大额开仓、反手、大额加仓（按回合累计或跨档）、浮亏加仓、大额平仓、疑似 / 确认强平、接近强平（三档）、战绩交易员动向 |
| 事实包 | 每个数字带来源路径和中英文展示串；覆盖不足的统计直接不出；措辞约束随包传递 |
| 可信度门 | 数据源过期、同步积压、交易员数据过期、与当前持仓矛盾、缺价格、无法获取上下文 → 阻断 |
| AI 总编辑 | 可解释的立项结论、账号推荐与沉默理由、后续追踪、风险标记；同语种角度相近时要求人工判断 |
| AI 记者 | 基于同一版事实包独立写中文 / 英文稿；不翻译；人工稿不被覆盖 |
| 稿件 | 不可变版本、来源（AI / 人工 / 模型 / 提示词版本）、引用事实、守卫报告、版本切换、全文检索 |
| 守卫 | 数字核对、条件禁用词、引用一致、X 长度、同语种近似重复 |
| 发布 | 复制文案（审计）、记录帖子链接（校验账号）、授权 / 预算 / 紧急停止检查、最终文本再守卫、撤稿 |
| 更正 | 事实实质变化 → 未发稿件标记需重新核验、已发帖子列入更正记录 |
| 图卡 | 位置卡 / 平仓卡 / 强平卡，SVG → PNG，记录模板版本与事实包哈希 |
| 账号 | 定位、受众、风格、事件类型范围、最低分、每日上限、授权与到期 |
| 管理 | 数据源健康、AI 模型（测试按钮）、AI 角色版本、提示词版本、用户与账号权限、费用、任务、审计、规则 |

## 6. 不做的事（明确的边界）

- 不自动发帖；不批量评论、不提及陌生用户、不组织互动。
- 不把同一篇稿换词后发到多个账号；不用随机延迟掩盖重复。
- 不猜测钱包背后的身份；不暗示内幕。
- 不生成仿交易所界面的截图。
- 不保证 X 原创内容奖励资格或收入。

## 7. 成功指标（Phase 1 → 4 逐步可量化）

| 指标 | 口径 |
|---|---|
| 事实错误率 | 发布后需更正的帖子 / 全部发布（目标 < 1%） |
| 守卫拦截率 | 守卫失败的 AI 草稿占比（衡量提示词质量，不是越低越好） |
| 选题转化 | 候选 → 发布的比例；被拒原因分布 |
| 账号差异度 | 同事件跨账号文本相似度分布 |
| 真实增长 | 每个账号相对自身基线的新增关注 / 千次曝光（Phase 4） |
