# 11 栏目与创新清单

原则：每个栏目都要回答“我们有什么别人没有的可核验数据”。数据依据以 00-audit.md 为准；标注“现在可做”的，是指现有 AlphaScope 表 + Newsroom 现有模块即可支撑。

## 1. 需求中列出的 12 个栏目：可行性评估

| 栏目 | 数据依据 | 现在能否做 | 关键事实风险与处理 | 阶段 |
|---|---|---|---|---|
| 巨鲸连续剧 | `position_episode` + 故事时间线（已实现） | 基础版已可用（交易员故事页、开篇 / 续集 / 结局） | 窗口时间；首次观测不是开仓 | P1 基础，P3 完整 |
| 神级交易员真实性调查 | `style_tag`(verified/OOS)、`timing_score`(BH q)、`copy_score_outcome`、`wallet_metric.reliability` | 可做（需新增“战绩卡”模板） | 只用完整周期；明示幸存者偏差（排行榜只看到留下的人）；OKX 只能谈方向 | P3 |
| 一周巨鲸成绩单 | Newsroom 自己的发布记录 + 同一回合后续事件 / 平仓 | 可做（数据都在 Newsroom 库里） | 必须包含失败案例；后续结果用当时可得数据，不回改原文 | P2 |
| 巨鲸反常行为榜 | 规模相对自身历史（完整周期最大仓位）、相对账户值 | 部分：只对成交已同步的约 2k 钱包 | 档案截断时不比；比率只在账户值可靠时 | P2 |
| 多空对决 | `research_frame`（BTC/ETH，专家组 vs 匹配对照组）、`/market/divergence` | BTC/ETH 可做 | `/market/divergence` 的两组有重叠，优先用 research_frame；永远标“观测样本” | P3 |
| 巨鲸翻车档案 | `fill.liquidation`、`okx_position.liquidated`、`wallet_metric.mdd` | 可做（确认强平事件已实现） | 疑似与确认严格区分；回撤是粗粒度 | P2 |
| 连胜终结者 | 完整周期序列 | 可做（连胜事实已实现，需要“连胜被打断”检测） | 连胜必须有已知起点（之前有亏损）；只算完整周期 | P3 |
| 谁提前布局了重大行情 | `swing_leg`、`leg_capture`、`/zones` | 可做，但只能是回顾 | 后验研究，必须写明“事后回看”；只用当时已有的持仓，不用事后成交美化 | P3 |
| 巨鲸行为相似性研究 | `/discover/similar`、成交时序 | 可做（研究稿） | 只描述“行为相似”，禁止推断同一控制人（守卫已有身份规则） | P3 |
| 公开交易追踪挑战 | Newsroom 发布记录 + 后续事件 | 可做 | 不删除失败；规则提前公开 | P2 |
| 巨鲸仓位生命周期可视化 | 回合 + 原始观测序列 | 可做（新增时间线图卡） | 标明采样间隔造成的不确定 | P3 |
| 市场叙事反转研究 | `market_snapshot` 历史、事件流 | 可做（BTC/ETH 更完整） | 不当作预测；AlphaScope 自己的研究结论是“没有足够证据支持共同领先信号”（docs/17），必须如实引用 | P3 |

## 2. 新提出的 12 个创意

### N1 排行榜收益 vs 真实可跟单收益
- 内容价值：OKX 排行榜 ROI 与“按带单仓位真实跟单”的回测收益常常差很多，这正是跟单用户最关心的问题。
- 传播机制：反常识对比（“榜首 +300%，跟单者只拿到 +40%”），天然引发讨论与收藏。
- 所需数据：`copy_backtest`（7/30/90 天）、`okx_leaderboard_row`。
- 现在能否实现：数据已有；需要 Feed 增加跟单回测端点（只读）。
- 实现成本：低（1 个 Feed 端点 + 1 个事实包类型 + 1 个图卡）。
- 事实风险：OKX 回测用当前资产做分母（`approx_equity`）；滑点与延迟是假设。必须随图注明。
- 持续栏目：是，每周一期。
- 竞争优势：需要长期归档 + 回测引擎，复制门槛高。
- 最小验证：手工挑 5 个榜单交易员发一期长帖，看收藏 / 转发率。
- 变现关联：直接导流到 AlphaScope 跟单评分页（高级会员）。

### N2 榜单幸存者偏差追踪
- 内容价值：跟踪“上过榜又掉下去”的交易员之后怎样，揭示只看榜单的偏差。
- 传播机制：“消失的榜首”故事性强；持续更新形成追更。
- 所需数据：`okx_presence`（dropped、streak）、`okx_position`。
- 现在能否实现：能（Feed 需增加 presence 端点）。
- 实现成本：低。
- 事实风险：掉榜原因未知（可能只是停止带单），不能写成“爆仓离场”除非有强平记录。
- 持续栏目：是，月度。
- 竞争优势：每日完整榜单归档是独有数据。
- 最小验证：一期 thread。
- 变现关联：研究报告素材。

### N3 强平价阶梯周报
- 内容价值：观测样本里，BTC/ETH 价格到哪个位置会触及多少名义仓位的强平价。
- 传播机制：交易者会在价格接近时回看这张图，形成“工具型内容”。
- 所需数据：`/market/liquidations`、`/market/structure`（只用交易所报告的强平价）。
- 现在能否实现：能（Feed 增加结构端点）。
- 实现成本：中（需要阶梯图模板）。
- 事实风险：只覆盖报告了强平价的仓位；全仓仓位的强平价会随账户变化；必须写“观测样本”。
- 持续栏目：是，每周或大波动时。
- 竞争优势：来自真实钱包级别持仓，而不是交易所模型估算。
- 最小验证：一张图 + 一句话，比较互动率。
- 变现关联：高级会员的实时版本。

### N4 预测公开账本
- 内容价值：AlphaScope 的研究预测（`research_forecast`，影子模式）事前登记、事后公开结果，包括失败。
- 传播机制：“我们说过什么、对了多少”的透明度建立信任。
- 所需数据：`research_forecast` / `research_evaluation` / `/research/conclusions` 的证据等级。
- 现在能否实现：数据已有；需要 Feed 端点。
- 实现成本：低。
- 事实风险：必须明说是研究性预测、样本量与显著性；不能当交易建议。
- 持续栏目：是，月度。
- 竞争优势：事前登记 + 不删失败，几乎没有竞争者愿意这样做。
- 最小验证：发布一期“上月预测成绩单”。
- 变现关联：研究订阅的信任基础。

### N5 资金费率与巨鲸方向背离
- 内容价值：资金费率显示拥挤方向，而高战绩钱包站在另一边时，信息量大。
- 传播机制：衍生品圈层高频讨论话题。
- 所需数据：`exchange_observation`（资金费率历史排名）、`research_frame`（BTC/ETH）。
- 现在能否实现：BTC/ETH 能。
- 实现成本：中。
- 事实风险：AlphaScope 因子实验室结论是“只是筛选假设，不是可交易优势”，必须照实写。
- 持续栏目：触发式。
- 竞争优势：钱包级方向 + 资金费率的组合少见。
- 最小验证：回看过去 3 次背离，写一篇复盘。
- 变现关联：衍生品账号的核心栏目。

### N6 谁拿得住：持仓时长画像
- 内容价值：盈利交易员与亏损交易员在持有时长上的差别（“亏损单拿得比盈利单久”）。
- 传播机制：教育性强，适合新手账号，易被收藏。
- 所需数据：`position_cycle.holding_hours`、完整周期盈亏。
- 现在能否实现：能。
- 实现成本：低。
- 事实风险：只用完整周期；样本说明。
- 持续栏目：季度研究。
- 竞争优势：成交级重建是独有能力。
- 最小验证：一篇长文。
- 变现关联：教育内容 → 会员转化。

### N7 风格变迁档案（Newsroom 自建历史）
- 内容价值：AlphaScope 的风格标签每次全量替换、没有历史；Newsroom 每次拉取的交易员上下文都存档（`trader_context_snapshot`），可以记录“某交易员从稳健型变成高风险”。
- 传播机制：“他变了”的人物叙事。
- 所需数据：Newsroom 自己的上下文快照。
- 现在能否实现：数据从上线日开始积累，3 个月后可用。
- 实现成本：低（查询 + 模板）。
- 事实风险：标签版本变化（s1→s2）要区分“规则变了”和“人变了”。
- 持续栏目：是。
- 竞争优势：时间换来的数据，无法补采。
- 最小验证：上线 30 天后先做内部报告。
- 变现关联：交易员档案付费页。

### N8 新上榜钱包的首秀观察
- 内容价值：新出现在 HL 排行榜、带着大仓位的钱包。
- 传播机制：时效性强。
- 所需数据：`/wallets/new`、雷达持仓。
- 现在能否实现：能。
- 实现成本：低。
- 事实风险：上榜时间不是开户时间；首次观测不是开仓；不能猜测身份（“疑似某机构新钱包”禁用）。
- 持续栏目：每日简报的一个固定段落。
- 竞争优势：一般；价值在于“写对”而不是独家。
- 最小验证：放入每日简报观察点击。
- 变现关联：弱。

### N9 跨所对照：HL 与 OKX 观测样本的多空差异
- 内容价值：链上透明钱包与中心化带单交易员在同一币种上的方向差异。
- 传播机制：“链上 vs 带单”对立叙事。
- 所需数据：`market_snapshot`（按 venue）。
- 现在能否实现：能。
- 实现成本：低。
- 事实风险：两个样本的人群、规模和计算口径都不同，只能并列，不能合并成“市场”。
- 持续栏目：每周。
- 竞争优势：同时持有两边样本的平台很少。
- 最小验证：一张对照卡。
- 变现关联：中。

### N10 读者提问 → 数据研究
- 内容价值：把评论区里能用数据回答的问题变成短研究。
- 传播机制：回应读者 → 读者转发 → 形成社区。
- 所需数据：Phase 4 读者洞察 + AlphaScope 研究 API。
- 现在能否实现：Phase 4（需要合法获取评论）。
- 实现成本：中。
- 事实风险：问题本身可能带错误前提，要先核实前提。
- 持续栏目：是。
- 竞争优势：响应速度 + 数据深度。
- 最小验证：人工挑 3 个问题手写回答。
- 变现关联：高（建立忠诚读者）。

### N11 故事结局复盘自动生成
- 内容价值：一个回合平仓后，自动生成“从首次报道到结局”的完整复盘，固定每章当时的事实版本。
- 传播机制：连续剧的“大结局”，引用原帖形成回链。
- 所需数据：Newsroom 故事 + 回合 + 发布记录（已有）。
- 现在能否实现：数据已有；需要复盘模板与 AI 角色。
- 实现成本：中。
- 事实风险：平仓盈亏若无成交只能是估算，需标注。
- 持续栏目：是。
- 竞争优势：完整的事实版本链只有我们有。
- 最小验证：手工挑一个已结束的故事做一期。
- 变现关联：公开故事页 → 会员。

### N12 数据纠错公告栏
- 内容价值：公开所有更正记录（什么错了、何时更正、原因）。
- 传播机制：反直觉的透明度，长期积累信誉。
- 所需数据：`correction_record`、撤稿记录。
- 现在能否实现：能。
- 实现成本：低。
- 事实风险：无。
- 持续栏目：常设页面。
- 竞争优势：可信度本身就是护城河。
- 最小验证：网站上放一个页面。
- 变现关联：间接（品牌信任）。

## 3. 建议的优先顺序

1. P2 立即：一周巨鲸成绩单、公开交易追踪挑战、N12 纠错公告栏（数据全在 Newsroom 内）。
2. P2–P3：N1、N2、N3、N4（各需要一个 Feed 只读端点）。
3. P3：神级交易员真实性调查、连胜终结者、多空对决、生命周期可视化、N11。
4. 积累型：N7 从上线日开始自动积累，3 个月后启用。
