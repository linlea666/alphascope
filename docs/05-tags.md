# 05 · 自动标签体系

标签不是荣誉，而是**有有效期、有证据、可失效**的研究结论。

## 1. 生成方式

**确定性规则 + 统计检验 + 聚类发现 + AI 解释**

| 环节 | 作用 | 约束 |
|---|---|---|
| 规则 | 按明确阈值计算候选标签 | 阈值写在配置里并带版本 |
| 统计检验 | 判断差异是否显著（置信区间、bootstrap、相对随机基准） | 不显著 → 不授予，或降为"疑似" |
| 聚类 | 在特征空间（行为 + 风险 + 盈利结构）上用 HDBSCAN 发现新风格；新簇由研究员命名后才成为正式标签 | 聚类只提出候选，不直接对外展示 |
| AI 解释 | LLM 把指标与代表性交易翻译成可读说明 | 只能引用已计算的数据，不能自行推断意图 |

## 2. 标签记录字段

`key`（如 `growth.small_capital.verified`）、名称（zh/en）、类别、定义、计算规则、关联指标、样本数量、证据时间区间、数据覆盖率、置信度（高/中/低）、状态（active / suspected / expired）、版本、`valid_from` / `valid_to`、失效条件、证据 JSON（指向具体的 round trip / 区间 / 事件 ID）。

失效时只写 `valid_to`，**不删除**，所以能回答"这个钱包历史上什么时候获得、什么时候失去这个标签"。

## 3. 标签树（v1）

### 3.1 成长与资金
| 标签 | 规则草案 | 最低样本 | 置信度要求 |
|---|---|---|---|
| 已验证小资金成长（<$1k / $1k–5k / $5k–10k / $10k–50k 起步） | allTime 曲线与资金流水都覆盖开户时点；起始资金 = 首次入金到首笔交易前的净值；资金流调整后成长倍数 ≥ 5；期间 MDD 不差于 −60%；≥ 3 个盈利月 | 逐笔覆盖 ≥ 180 天 | 高 |
| 疑似小资金成长 | 同上，但开户时点或资金流水覆盖不完整 | — | 中/低，并写明缺什么 |
| 大资金稳健管理 | 平均净值 ≥ $1M，MDD 不差于 −20%，正收益月占比 ≥ 60% | ≥ 6 个月 | 高 |
| 高成长潜力新交易员 | 账户年龄 < 90 天，潜力引擎连续两期触发 | — | 中 |

### 3.2 风险收益结构
| 标签 | 规则草案 | 最低样本 |
|---|---|---|
| 稳健复利 | 月度正收益占比 ≥ 70%；MDD 不差于 −15%；去掉最好 1 周后收益仍 > 0；没有清零风险区间 | ≥ 6 个月、≥ 50 笔 |
| 高盈亏比 | 盈亏比 ≥ 2.5 且期望值 bootstrap 95% 下限 > 0；最大单笔贡献 < 30% | ≥ 50 笔 |
| 高胜率低收益 | 胜率 ≥ 70% 但盈亏比 < 0.7 | ≥ 50 笔 |
| 低胜率高回报 | 胜率 ≤ 40% 且期望值显著为正 | ≥ 80 笔 |
| 低杠杆高效率 | 平均有效杠杆 ≤ 3×，风险调整收益位于同类前 25% | ≥ 90 天 |
| 高风险不可跟单 | 有效杠杆经常 ≥ 20×，或距强平 < 5% 的时间占比高，或有强平记录 | 任意（负面标签只要有证据即可） |

### 3.3 纠错与执行
| 标签 | 规则草案 | 注意 |
|---|---|---|
| 快速止损 | 亏损单平均持仓时间 ≤ 盈利单的 0.5 倍；单笔亏损 P95 受控 | 交易频繁不等于纠错能力强 |
| 有效反手 | 反手后 round trip 的期望值 > 0 且显著高于该钱包的整体期望值 | 来回止损但期望值为负 → 标记"无纪律反复" |

### 3.4 市场环境与方向
| 标签 | 规则草案 | 最低样本 |
|---|---|---|
| 宏观趋势捕捉 | 在 ≥ 3 个独立的重大行情事件中，建仓时间早于事件中点、方向正确，捕获比例显著高于同类随机基准 | 每个事件单独评估；事件定义带版本 |
| 顶部做空 / 抄底反弹 | 在局部极值（只用当时可得数据定义）附近 ±X% 区间建立反向仓位并盈利，次数显著多于随机 | ≥ 5 次独立机会 |
| 单边趋势高手 / 震荡高手 | 分市场状态的期望值显著为正且显著高于其他状态 | 每种状态 ≥ 20 笔 |
| 极端行情生存 | 在高波动状态中 MDD 优于同类中位数且未被强平 | ≥ 2 次极端事件 |

### 3.5 标的偏好
BTC/ETH 专业、山寨币专业、多币种稳定盈利：按币种的盈亏贡献与 HHI 判断，要求每个主要币种的期望值都为正。

### 3.6 动态状态
| 标签 | 规则草案 |
|---|---|
| 近期显著改善 | 潜力引擎的信号（见 01 第 4 节） |
| 能力衰退预警 | 近 30 天期望值、MDD、杠杆相对自身 90 天基线显著变差（任两项） |

### 3.7 账户类型（描述性）
疑似做市（高频双边挂单、极短持仓、收益与成交量高度相关）、疑似套利（多空对冲仓位、资金费驱动）、Vault、子账户汇总。

### 3.8 异常研究（中性）
| 标签 | 规则草案 | 措辞 |
|---|---|---|
| 事件前异常交易 | 公开事件前 T 小时内，相对自身历史基线的仓位规模 z-score ≥ 3，方向与随后行情一致；同一钱包在 ≥ 2 个独立事件中重复出现 | 只说"事件前异常仓位 / 异常领先行为 / 值得进一步研究"，**不说内幕、不做身份推断、不暗示违法** |

必须同时排除：公开信息已发布（以可核实的发布时间为准）、该钱包常规策略本来就会在类似时点建仓、以及事后挑选赢家（必须统计同期所有类似仓位的钱包，包括亏损的）。

## 4. 置信度

```
置信度 = min(样本充分度, 数据覆盖率, 统计显著性, 数据可信度)
  样本充分度：n / 该标签最低样本，截断到 [0, 1]
  数据覆盖率：证据窗口内实际拿到数据的比例
  统计显著性：p 值或置信区间是否排除 0
  数据可信度：输入指标的 reliability
高 ≥ 0.8，中 0.5–0.8，低 < 0.5（低置信度标签只在研究视图中展示）
```

## 5. 更新机制

- 每次相关数据刷新后重新评估（B 层每 7 天，A 层每天）。
- 状态转换：`suspected → active`（证据补齐）、`active → expired`（触发失效条件，写入 valid_to 和原因）。
- 规则改版：新版本并行计算一个周期，对比差异后再切换；旧版本结果保留。
- 每个标签记录"授予时系统知道什么"（数据截止时间），用于回测标签本身的预测力。
