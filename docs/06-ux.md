# 06 · 页面与交互规划

## 1. 信息架构

导航按用户任务分组，而不是把 12 个模块平铺：

| 一级导航 | 包含 | 阶段 |
|---|---|---|
| **情报总览** | 数据新鲜度、核心计数、初筛候选、新发现、分层与质量分布 → P1 增加潜力名单、衰退预警、排行榜流入流出 | P0 ✅ |
| **排行榜** | 去噪/原始、时间窗口、筛选、排序 → P1 增加特色榜单与自定义保存 | P0 ✅ |
| **发现** | 潜力名单、三层研究成果、策略标签浏览、相似钱包 | P1 |
| **交易员** | 单个钱包研究页（深链接） | P0 ✅ |
| **研究** | 事件研究中心、历史行情回放、对比、研究报告 | P2 |
| **跟单实验室** | 历史回测、影子跟单、延迟压力测试、组合 | P2 |
| **我的** | 观察清单、预警 | P2 |
| **数据健康** | 采集任务、预算、表规模、归档 | P0 ✅ |

## 2. 已实现页面（P0）

### 情报总览 `/[locale]`
- 顶部：数据新鲜度（排行榜快照、排行榜检查、增强采集三个时间）。
- 计数卡：已入库、当前在榜、B 层、已增强（占 B 层比例）、24h / 7d 新发现。
- **初筛候选（30D，未验证）**：明确写出条件，并说明这只代表"值得研究"。
- 资源分层条形图 + 每层的说明。
- 数据质量标记分布 + 每个标记的含义。
- 新发现钱包（不含首次全量导入）。

### 排行榜 `/[locale]/rankings`
- 时间窗口切换：1D / 7D / 30D / 全部（**没有 90D**，因为官方没有）。
- 模式：去噪（默认）/ 原始；页面下方写明当前排除了哪些标记。
- 筛选：搜索（地址前缀 / 名称）、最低/最高净值、层级、只看已增强。
- 可排序的列：净值、PnL、ROI、成交量、30D TWR、30D MDD；表头标注"官方 / 自算"。
- 每行：质量标记徽标（悬停显示说明）、层级徽标、30D 可信度（非"可靠"时显示）。
- 所有状态都在 URL 里，可以直接分享或收藏。

### 交易员 `/[locale]/trader/[address]`
1. 头部：名称、层级、标记、完整地址（复制 / Hypurrscan）、官方净值；已跌出排行榜时给出提示。
2. 第一行三栏：官方排行榜数值 · 身份与数据覆盖（首次发现、来源、portfolio 采集时间、层级历史）· 当前持仓（方向、名义价值、未实现盈亏、杠杆、强平价）。
3. 账户净值与累计 PnL 双轴图（近 30 天 / 全历史切换，可缩放）。两条线分开时说明有资金流动。
4. 自算指标表：30D / 90D / 180D / 365D / 全部，每行带数据跨度、点数、中位间隔、可信度和原因说明；历史不足的窗口显示"数据不足"。
5. 排行榜快照历史。

### 数据健康 `/[locale]/data-health`
最近成功时间、API 权重预算（24h 用量 / 容量）、调度说明、表行数、原始归档体积、最近 40 次任务（状态、耗时、摘要、错误）。

## 3. 交易员页的完整规划（P1–P2）

| 屏 | 内容 | 阶段 |
|---|---|---|
| 顶部 | 身份、三层归属、Skill / Copyability 评分（含置信度）、核心标签 | P1 |
| 第一屏 | 资金曲线、关键收益、风险概况 | P0（粗粒度）→ P1（逐笔） |
| 第二屏 | 交易风格画像（DNA 雷达）、策略标签、优势与弱点 | P1–P2 |
| 第三屏 | 持仓周期列表、交易历史、币种盈亏贡献 | P1 |
| 第四屏 | 重大行情中的代表性交易（时间轴回放） | P2 |
| 第五屏 | 模拟跟单结果、延迟压力测试、评分历史 | P2 |
| 第六屏 | AI 研究报告：每条结论可展开到原始成交 | P2 |

**联动**：图表上选中一段时间 → 下方交易列表过滤到该区间；点击一笔交易 → 图表上高亮开平仓点。

## 4. 设计规范

| 项目 | 规范 |
|---|---|
| 主题 | 深色优先，可切换浅色；颜色都定义为 CSS 变量（`globals.css`），图表从同一套变量取色 |
| 盈亏颜色 | 涨/盈 `--up`（绿），跌/亏 `--down`（红），中性 `--muted`；警示 `--warn` 只用于数据质量 |
| 数字 | 等宽数字（`.num`）；货币按语言做紧凑格式（中文用万/亿，英文用 K/M/B）；收益带正负号，占比不带 |
| 时间 | 全站使用 UTC 并显式写明"UTC" |
| 来源标注 | 官方 / 自算必须区分；自算指标必须带可信度 |
| 空状态 | 说明为什么没有数据，以及什么时候会有（例如"后台每 10 分钟增强一批"） |
| 错误状态 | API 不可用时显示可操作的提示，不显示空表格 |
| 语言 | 所有界面文字走 `messages/{zh,en}.json`；PnL / ROI / TWR / MDD 等缩写两种语言都保留英文 |
| 响应式 | 桌面优先；表格横向滚动，筛选栏自动换行 |

## 5. 核心组件

`Panel`、`Stat`、`Badge`（标记 / 层级 / 可信度）、`Freshness`、`AddressLink`、`CopyButton`、`EquityChart`（ECharts，双轴，随主题重绘）、`ApiErrorState`。P1 增加：`ScoreCard`（总分 + 分项 + 置信度）、`TagChip`（悬停展开证据）、`EvidenceDrawer`（结论 → 指标 → 原始成交）、`TradeTimeline`。
