# 14 · 体验打磨与发现功能（M3）

这一轮修了两个缺陷，按产品审查结论把体验和发现功能一次做完。所有新数字都来自已归档的真实成交 / 交易所数据，并写明统计口径和样本量。

## 缺陷修复

| 问题 | 原因 | 处理 |
|---|---|---|
| 波段持仓者选 OKX / 全部时 500 | OKX 部分平仓的未平仓周期把 `exits` 写成 JSONB `null`，`jsonb_array_elements` 报错 | 推导时写空数组；迁移 0012 修存量；查询用 `nullif(x, 'null'::jsonb)` 兜底 |
| 关键价位预设看起来切不过去 | 表单是非受控的 `defaultValue`，客户端导航不重新挂载，`<select>` 停在旧值 | 表单按查询加 `key`；加「清除第二个条件」和排序 |
| 所有错误都显示「无法连接后端」 | `ApiErrorState` 不区分状态码 | 按 0 / 422 / 5xx 分别提示，5xx 附重试 |
