# 13 · 多风格交易员发现

> 目标：不做一张"Top 100 高手榜"，而是按风格分别找人。用户可能想找稳定的 BTC 波段交易员，也可能想找熊市里擅长做空、或者低回撤低频的人。每个标签都给出：用了哪些规则、交易员的实际数值、样本量、有没有通过样本外检验。标签是研究线索，不是跟单建议。

## 1. 数据

**周期**：两个交易所的已平仓仓位周期（`position_cycle`）。
- OKX：由历史仓位派生的完整仓位，约 2,170 人；
- Hyperliquid：由逐笔成交重建的周期，只覆盖已归档成交的钱包。

**额外输入**：

| 输入 | 来源 |
|---|---|
| 账户规模 | OKX 带单资产 / Hyperliquid 账户净值 |
| 强平次数 | OKX 的 `liquidated` 字段；Hyperliquid 用"被强平地址是本钱包"的强平成交，同一币种同一分钟算一次 |
| 杠杆中位数 | OKX 的 `lever` |
| 节奏评分 | `timing_score` 中 all 窗口、全部币种的结果 |
| 整段行情捕获率 | `leg_capture` |
| 当前持仓浮亏 | 市场雷达最近一次轮询（`trader_position.upl`） |

## 2. 因子（`app/factors/compute.py`，版本 f1）

每个因子都带样本量 n，并计算三个窗口：全部历史、近 90 天、样本外截止日之前（只用于检验）。缺少输入时记为未知，**不当作 0**。

| 类别 | 因子 |
|---|---|
| 收益质量 | 已实现净盈亏、胜率与 95% Wilson 下限、盈亏比、单笔期望（名义金额的 bp）、最大单笔 / 前 5 笔占总盈利、盈利月份占比、活跃月数 |
| 风险 | 已实现最大回撤（美元，以及除以"账户 + 累计盈利峰值"）、强平率、杠杆中位数、当前浮亏 / 账户 |
| 行为 | 盈利单与亏损单的持仓时长中位数及二者之比、4 小时内仓位占比、空单占比 |
| 方向与币种 | 空单的盈亏、盈亏比、胜率下限；主力币种的占比、盈亏、盈亏比、胜率下限；币种集中度（HHI） |
| 级别 | 波段、"波段 + 大周期"的数量、净盈亏、盈亏比、胜率下限 |
| 时机 | 各级别节奏超额与 q 值、买入 / 卖出位置分、买在低点 / 卖在高点相对随机基准的倍数、整段行情捕获率 |

## 3. 风格规则（`app/factors/styles.py`，版本 s2）

| 风格 | 样本要求 | 规则 |
|---|---|---|
| 稳健复利 | ≥30 个周期，≥4 个月 | 盈利月份 ≥60%，盈亏比 ≥1.3，最大单笔 ≤35%，已实现回撤 ≤35%，强平率 ≤2%，当前浮亏 ≤15% |
| 大趋势 | 波段 + 大周期 ≥5 个 | 这部分整体盈利；且大周期或波段节奏 q < 0.1，或整段行情捕获率 ≥30%（满足其一） |
| 波段高手 | 波段周期 ≥15 个 | 波段盈亏比 ≥1.3，胜率下限 ≥40%，整体盈利 |
| 抄底 | ≥15 个周期 | 买入位置分 ≥0.7，买在低点的比例是随机基准的 1.5 倍以上，多单整体盈利 |
| 摸顶做空 | ≥15 个周期 | 空单盈利，空单盈亏比 ≥1.3，空单胜率下限 ≥40%，卖出位置分 ≥0.65 |
| 短线 | ≥100 个周期，4 小时内仓位 ≥60% | 盈亏比 ≥1.2，整体盈利，胜率下限 ≥45%（标注：难以靠跟单复制） |
| 低回撤 | ≥20 个周期，≥3 个月 | 已实现回撤 ≤10%，整体盈利，没有强平，当前浮亏 ≤5% |
| 币种专精 | 主力币种 ≥20 个周期 | 主力币种占比 ≥60%，在该币种上盈利，盈亏比 ≥1.3，胜率下限 ≥45% |
| 高风险投机（风险识别） | ≥10 个周期 | 满足任意一条：强平率 ≥5%、杠杆中位数 ≥30 倍、最大单笔 ≥60%、亏损单持仓时长 ≥ 盈利单的 10 倍 |

**能力风格的共同否决条件**（高风险投机不适用）：只要已知不满足其中一条，就直接不打这个标签。
1. 整体已实现净盈亏为正；
2. 亏损单持仓时长中位数不超过盈利单的 10 倍（至少有 2 笔亏损时才生效）；
3. 当前浮亏不超过账户的 30%（市场雷达未轮询过的交易员，这一项为未知，不否决）。

**状态**：

| 状态 | 条件 |
|---|---|
| 证据不足 | 样本要求不满足 |
| 观察中 | 规则至少 3 条，只差一条（或其中一项数据未知） |
| 初步候选 | 全部规则在完整历史上成立 |
| 已验证 | 同时通过样本外检验 |

**样本外检验**：
1. 用 90 天前的数据（只用当时已平仓的周期，跳过"当前浮亏"这种非时点数据）判定是否满足规则；
2. 再看之后同类周期：至少 5 个、净盈亏为正、盈亏比 ≥1；
3. 并且之后的**全部**周期整体盈利。

依赖节奏评分的风格（大趋势、抄底）无法按历史时点重算，最高只到初步候选。

**得分**：按每个风格的代表因子排序；盈亏比类封顶 5 倍，再乘以置信度。置信度 = 样本量 ÷ 样本要求的 3 倍，最高为 1。

## 4. 真实数据中发现、并已据此修正的问题（2026-11-17）

1. **只平盈利单、亏损单死扛**
   - 现象：有人胜率约 98%、盈亏比上百，月月盈利，但当前持仓浮亏远超带单资产。例如资产 6.6 万美元，浮亏 11.2 万美元，最早的亏损仓位拿了一年多。只看已平仓记录，他们会被评为"稳健复利·已验证"。
   - 修正：加入"当前浮亏 / 账户"和"亏损 / 盈利持仓时长比"两项，并设为否决条件。
2. **扛单污染按级别切分的统计**
   - 现象：亏损单被拿得久，就从"波段"滑进了"大周期"。波段子集里全是盈利单，盈亏比显示为 ∞，而这个人的大周期部分在亏钱。
   - 修正：加入整体盈利否决；样本外检验同时检查之后全部周期的盈亏；按持仓时长比否决。
3. **官方小分母收益率误导周榜**
   - 现象：Hyperliquid 官方 ROI 用很小的起始资金做分母，会出现赚 926 美元却显示 +926% 的情况；周榜上还出现过回撤 -98% 的账户。
   - 修正：周 / 月榜里 Hyperliquid 的收益率改为 盈亏 ÷ 当前净值，并要求盈亏 ≥1,000 美元、已知的 30 天回撤不差于 -50%。

## 5. 页面

- **`/discover` 风格发现**：9 个风格页签，显示已验证数和"候选 + 已验证"数；可按交易所、状态、排序方式（风格得分 / 置信度 / 净盈亏）筛选。每行列出关键因子，可展开证据链（规则、数值、阈值、n，否决项单独标记，以及样本外结果）。
- **交易员页「能力画像与证据链」**：列出风格标签和关键因子，对比全部历史与近 90 天。
- **首页「本周 / 本月表现最佳」**：分交易所展示，有样本和风险门槛，并注明"短期表现，不代表能力已验证"。
- **导航**：研究类页面（大周期、节奏榜、波段持仓者、关键价位）收进「研究」菜单。

## 6. 调度与限制

- **调度**：worker 每 6 小时重算一次（约 20 秒）；也可以手动执行 `alphascope styles`。
- **Hyperliquid 覆盖有限**：只有已归档成交的钱包才有周期，大多数 Hyperliquid 钱包还没有风格标签。随着成交归档推进，覆盖会扩大。
- **"当前浮亏"依赖市场雷达**：雷达未轮询过的交易员，"稳健复利"和"低回撤"最多只能到观察中。
- **OKX 的局限**：只有完整仓位，加减仓时点不可见；持仓周期按首次开仓到最终平仓计算。
- **下一步**：用阶段 3 的离线跟单回放（不同延迟与成本）检验这些标签选出的人，在可观察到之后是否仍然可以复制。
